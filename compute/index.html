1. The idea: one thread per element

The GPU runs one thread per number, each thread squares its own element and writes down which workgroup and thread it was, so you can see the work being split up. Twenty numbers is far too small to be worth sending to a GPU. It is here only to show the shape of the thing. 



    
2. The point: the same idea, a million times over

    

      Every pixel of a Mandelbrot zoom is an independent loop of up to a few hundred multiplications,
      which is exactly the shape the GPU wants: identical work, no communication, one thread per
      pixel. Same maths in both cases, run both and compare. The GPU time includes uploading the
      parameters and reading every pixel back to the CPU. The CPU run freezes the page while it
      works, which is a fair part of the comparison.
